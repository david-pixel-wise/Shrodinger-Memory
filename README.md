# Shrödinger Memory

This thesis it’s my personal way, to learn **quantum computing** and all the potential behind it. Practice has helped me always a lot to discover dynamics that sometimes are difficult to understand. Writing source code with the objective of learn something complex like quantum computing is a good interactive way that I hope will let me discover something new about what I’m thinking about *reality*.

For this reason I have decided to create a *memory game* that can show some interesting properties of quantum computing, especially for the **entanglement state**. The source code that I have created in **Python** with the **Qiskit** module, will be tested on a real quantum computer to compare my analysis and experience with a *real* use case.

The name “*Schrödinger Memory*” has been chosen because one of the most important experiment designed by the physicist **Erwin Schrödinger** was to image a cat that was in an uncertain state between life and death.

Since I love cats, and I don’t want to hurt any animal for this experiments; I have thought that the creation of a game to prove the **superposition** of quantum bits could be a good exercise to better learn how is moving the reality of quantum computing.

The proprieties that are expressed from quantum computing are really different from the classical physic used by modern computers based on semiconductor and electromagnetism, my experiments in this thesis are addressed to better understand something never tested before on *classical computers* like the **entanglement** state, with two qubits.

The development of this game give me also, the possibility to improve my programming skills with the creation of a source code that respect my vision about **freedom in technology**.

To realize the source code I have used only **free** and **open source software**, because the technology that we are creating have to consider ethical and philosophical values that grant everyone the utilization, analysis and modification of the code realized with this experiments; like the *four freedoms* of **FOSS**:

*Freedom 0: The freedom to run the program as you wish.*<br>
*Freedom 1: The freedom to study how the program works.*<br>
*Freedom 2: The freedom to redistribute copies so you can help others.*<br>
*Freedom 3: The freedom to distribute copies of your modified versions to others.*<br>

The new paradigm of using computers include the **artificial intelligence** (later in the text **AI**), and for this reason I have used some AIs in *oversight mode*, because it is the best way to solve problems avoiding humans and machines errors; this way to work gave me the ability to speedup the development of source code, granting me more time to: read new articles, follow quantum courses or fixing **bgus**.

Before starting with my thesis, I would like to apologize for any inaccuracies or omissions that may appear in this work.

With this thesis, I simply attempt to write down, with humbleness, the method I applied to approach studying quantum computers.

*I apologize once more, for the inaccuracy that may appear in this text.*
